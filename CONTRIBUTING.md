# Contributing to Verdecito

Thank you for considering a contribution. Verdecito is small on purpose; the shortest contribution is the most useful.

## Ways to contribute

1. **Improve the spec.** Open an issue using the `object change` template if you want to suggest a field, an enum value, or a new object type.
2. **Improve the reference instance.** Open a pull request with a clearer summary, better relationships, or a corrected status.
3. **Fork and adapt.** The license allows it. You don't need permission. Attribution for CC BY content is required.

## Scope of v0.1

This is the first public scaffold. Many things are intentionally deferred:

- Rendering (Astro, websites).
- Bilingual content. Today, English is the working language.
- Images and assets.
- Validator tooling.

## How to propose changes

- Open an issue first if your change touches the spec or schema.
- Keep PRs focused. One change per PR.
- Reference the relevant spec section or instance object by URN.
