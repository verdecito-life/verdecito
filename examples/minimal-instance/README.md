# Minimal instance — a starter template

The smallest valid Verdecito instance: a tracker, an identity, one seed, and one quest.

## How to use it

1. Copy this folder to your own location.
2. Rename `example` to your instance name (e.g. `mygarden`).
3. Update IDs in frontmatter (`seed:example:000` → `seed:mygarden:000`, etc.).
4. Replace placeholder content with your own.
5. Declare your skin (your own, or reuse `verdecito`).

Spec compatibility: `0.1.0`. Validate against schemas in `spec/schema/`.
