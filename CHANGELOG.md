# Changelog

All notable changes to Verdecito will be documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html) for the spec.

## [Unreleased]

### Added
- Initial public scaffold: spec, default skin, reference instance, minimal example.
- Object schemas for tracker, identity, seed, quest, artifact, channel (real).
- Object schemas for sprint, task, ask (experimental stubs).
- Spec conventions: identifiers, frontmatter, lifecycle, filenames.
- Default skin (Verdecito) with vocabulary mapping and render policy.
- MIT license for code/spec, CC BY 4.0 for content.

### Notes
- Astro rendering, bilingual content, and image strategy are deferred to v0.2+.
- The `project` object type is intentionally deferred until there is a real instance to validate it.
