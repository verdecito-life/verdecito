# Spec v0.1.0 — Initial release

First public schema and conventions. Everything in v0.1.0 is `experimental` by default — field shapes may evolve before v1.0. Identifiers will not.

## Real schemas in v0.1.0

- `tracker`, `identity`, `seed`, `quest`, `artifact`, `channel`

## Experimental stubs

- `sprint`, `task`, `ask` — fields will firm up in v0.2.

## Intentionally deferred

- `project` — re-evaluated for v0.2 when there are multiple seeds per project.
- Astro rendering and bilingual content — parked for v0.2+, not canceled.
- Image and asset strategy — parked.
- Layered overlay composition — parked.
- Validator CLI — parked.

## Compatibility

No prior version to migrate from. Future versions will document migration paths from v0.1.0.
