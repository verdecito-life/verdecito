# Verdecito skin

The default skin: how the model is presented as Verdecito-the-public-project.

## Files

- [`manifest.yaml`](manifest.yaml) — skin metadata.
- [`vocabulary.yaml`](vocabulary.yaml) — engine terms → Verdecito-skin labels.
- [`render-policy.yaml`](render-policy.yaml) — what surfaces where.

## What a skin is

A skin maps the canonical model to a specific public surface. Vocabulary, render policy, and (later) theme and layout. A skin does not change the model; it changes how the model appears.

Another instance may declare a different skin without changing the underlying object data.
